# 从 2.x 到 3.x

3.0.0-alpha.1 仍是同一个仓库、同一个 npm 包名 `stinky-cobbler`。这次没有把包版本改成 `3.0.0` 或 `3.0.0-alpha.1`。发布契约要求包版本是稳定的 `x.y.z`，而 `3.0.0` 需要四个宿主的真实冒烟记录。包版本因此保持 `2.0.2`。

## 保留

- 可执行文件仍是 `stinky-cobbler` 和 `stinky-cobbler-mcp`。
- Task、Approval、Lease、WriteIntent 和哈希链账本还在。这些命令已 deprecated，不再扩展。
- Cooperative Mode 不变。它不是操作系统沙箱。宿主自己的文件工具、Shell 和第三方 MCP 可以绕过它。

## 新增

- `toolkit init`、`plan`、`apply`、`rollback`、`doctor`、`list`。
- 用户规格在 `$XDG_CONFIG_HOME/stinky-cobbler/toolkit.yaml`。
- 受管文件有 sidecar 和内容寻址备份。手改后是冲突，不会被覆盖。

## 这个 alpha 没有做

- 没有四个宿主的安装冒烟，状态是 `UNKNOWN / PENDING`。没有 tag，没有 `npm publish`。
- 不展开 bundle。不抓取 `git+` 或 npm 来源。没有 `toolkit search`。
- 不执行来源里的脚本。
- Gemini CLI 不在范围内。
- `gate` 的 P0（D-04 到 D-07、D-12）留在 2.x 清单，这个 alpha 不修。

已经写过、但仍包含已删除字段 `mode` 或 `allowLocalL0Exploration` 的 workspace，schema 校验会失败。没有只警告、不失败的自动迁移。
