# 从 2.x 到 3.x

3.0.0-rc.1 仍是同一个仓库、同一个 npm 包名 `stinky-cobbler`。包版本是 `3.0.0-rc.1`，不是 `3.0.0`。四个宿主的真实冒烟还没有，所以 GA 发布被挡住。没有 tag，也没有 `npm publish`。

## 保留

- 可执行文件仍是 `stinky-cobbler` 和 `stinky-cobbler-mcp`。
- Task、Approval、Lease、WriteIntent 和哈希链账本还在。这些命令已 deprecated，不再扩展。
- Cooperative Mode 不变。它不是操作系统沙箱。宿主自己的文件工具、Shell 和第三方 MCP 可以绕过它。

## 新增

- `toolkit init`、`plan`、`apply`、`rollback`、`doctor`、`list`、`lock`、`update`。
- `toolkit search` 在目录 API 核实前失败关闭，不写盘。
- `toolkit memory show` 和 `edit` 只碰受管段落。
- 用户规格在 `$XDG_CONFIG_HOME/stinky-cobbler/toolkit.yaml`。
- 受管文件有 sidecar 和内容寻址备份。手改后是冲突，不会被覆盖。
- 本地、`git+` 和 `npm:` 来源可以锁成内容 hash。`apply` 使用锁定字节。来源里的脚本不会执行。
- bundle 只展开 lock 里已经解析的 include。

## 仍然没有做

- 没有四个宿主的安装冒烟，状态是 `UNKNOWN / PENDING`。没有 tag，没有 `npm publish`。GA 发布被挡住。
- `skills.sh:` 不抓取。
- Gemini CLI 不在范围内。
- `gate` 的 P0（D-04 到 D-07、D-12）留在 2.x 清单，这个版本不修。

已经写过、但仍包含已删除字段 `mode` 或 `allowLocalL0Exploration` 的 workspace，schema 校验会失败。没有只警告、不失败的自动迁移。

## 包内资源路径变更（3.0）

运行时读取、随 npm 包发布的静态数据从仓库根目录迁到 `resources/`。`resources/toolkit/` 是 3.x，`resources/gate/` 是冻结的 2.x。`entry install-host` 写进宿主的路径不变（例如 `~/.codex/skills/stinky-cobbler/SKILL.md`、`~/.zcode/skills/stinky-cobbler/SKILL.md`、`~/.zcode/commands/stinky-cobbler.md`）。受管文件路径也不变。

| 旧路径 | 新路径 |
|---|---|
| `schemas/toolkit.schema.json` | `resources/toolkit/toolkit.schema.json` |
| `schemas/*.json`（其余） | `resources/gate/schemas/` |
| `policies/` | `resources/gate/policies/` |
| `profiles/` | `resources/gate/profiles/` |
| `packs/<id>/pack.yaml` | `resources/gate/packs/<id>/pack.yaml` |
| `plugins/builtin.yaml` | `resources/gate/plugins/builtin.yaml` |
| `examples/<name>/task.json` | `resources/gate/examples/<name>/task.json` |
| `templates/skill-core.md` | `resources/gate/skills/templates/skill-core.md` |
| `templates/hosts/codex.md`、`templates/hosts/zcode.md` | `resources/gate/skills/templates/hosts/codex.md`、`resources/gate/skills/templates/hosts/zcode.md` |
| `.codex/skills/stinky-cobbler/SKILL.md` | `resources/gate/skills/codex/SKILL.md` |
| `.zcode/skills/stinky-cobbler/SKILL.md` | `resources/gate/skills/zcode/SKILL.md` |
| `.zcode/commands/stinky-cobbler.md` | `resources/gate/skills/zcode/commands/stinky-cobbler.md` |
