# 威胁模型与权限设计

## 目标

Stinky Cobbler 默认防止：上下文污染、跨工作空间访问、Secret 泄露、Agent 越权、审查失独立、并行写冲突、外部副作用误执行与提示注入。

## 核心规则

```text
默认只读
默认拒绝
委派不扩权
能力短时有效
高影响动作需审批
所有外发有去向和证据
```

## 数据分类

| 分类 | 示例 | 默认处理 |
|---|---|---|
| public | 已公开文档 | 可在允许 Workspace 内处理 |
| internal | 内部草稿、流程文档 | 仅 Workspace 内 Agent |
| confidential | 合同、客户数据、财务资料 | 受限 Agent + 目的绑定 |
| restricted | 身份信息、受监管数据、Secret | 默认拒绝；需明确合规策略 |

## 影响等级

| 等级 | 行为 | 默认策略 |
|---|---|---|
| L0 | 检索、总结、草拟 | 可自动执行 |
| L1 | 内部草稿、标签、临时任务 | 可预授权，完整审计 |
| L2 | 更新 CRM、提交代码、修改正式文档 | 显式授权或策略预授权 |
| L3 | 发邮件、公开发布、删除、签署、付款 | 人工确认；可要求双人审批 |

## 委派约束

```text
child_permissions ⊆ parent_permissions ∩ task_policy_permissions
```

子 Agent 不得因为被委派而获得更高数据密级、更大工具权限或更宽外发范围。

## 默认拒绝项

```text
真实 Secret、Token、私钥
未授权外部网络传输
跨 Workspace 文件/资料读取
自动 Git push / 自动部署
自动邮件/社媒发布/付款/签署
删除正式数据、清空队列、删除集群资源
将外部文档指令当作系统策略
```

## 主要威胁与控制

| 威胁 | 控制 |
|---|---|
| 上下文污染 | fresh Agent、Task Capsule、FACT/DECISION/PROPOSAL/UNKNOWN |
| 路径越权 | Workspace allowlist、denylist、符号链接校验 |
| Secret 泄露 | 默认拒绝 Secret 文件、日志脱敏、输出过滤、短时令牌 |
| Prompt 注入 | 外部资料一律是不可信输入，不能改变 Policy 或 Capability |
| 权限膨胀 | Capability Lease 绑定 role/task/scope/expiry/tool calls |
| 审查失独立 | 实现者与审阅者角色互斥 |
| 并行写冲突 | writeSet 锁、隔离工作区、写任务串行 |
| 建议幻觉传播 | PROPOSAL 未批准不能进入执行 Capsule |
| 外部误操作 | L2/L3 审批 Gate、目的与去向 allowlist |
| 审计缺失 | Artifact provenance、Audit Event、Receipt Archive |

## 审批要求

| 动作 | 最低要求 |
|---|---|
| 创建草稿 | 策略允许时自动 |
| 修改内部正式产物 | 显式授权或预授权 |
| 提交代码/创建 PR | 明确用户/负责人批准 |
| 数据库迁移 | 明确批准 + 回滚方案 |
| 对外发送消息 | 人工确认收件人、内容、去向 |
| 公开发布 | 人工确认；组织场景确认代表权 |
| 删除 | 人工确认；受监管场景可要求双人审批 |
| 支付、签署、医疗/法律最终结论 | 永不由 Agent 单独完成 |

## 证据最小化

Audit/Event Ledger 只保存：

```text
taskId、角色、策略版本、工具摘要、产物引用、审批引用、命令退出码、hash、脱敏短摘要
```

不保存：

```text
完整对话、原始推理、真实 Secret、完整敏感文件、完整客户资料、完整队列 payload
```
