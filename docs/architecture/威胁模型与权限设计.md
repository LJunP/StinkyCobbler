# 威胁模型与权限设计

> **当前实现边界。** 当前定位是 Cooperative Mode 下 Codex/ZCode 本地仓库的受控执行与审计层。以下控制只覆盖经 Stinky Cobbler CLI/MCP 路由的操作；不是 OS 沙箱、宿主隔离、全本地/离线保证或真实身份系统。每组候选的 Codex/ZCode E2E 必须单独验证。

## 目标

Stinky Cobbler 在 Cooperative Mode 内降低路径越权、敏感路径读取、Task/Lease 扩权、写前漂移和未留痕变更风险。它不能防止宿主绕过控制面，也不保证上下文隔离、审查独立、并行进程隔离或外部系统安全。

## 核心规则

```text
默认只读
默认拒绝
委派不扩权
能力短时有效
高影响动作需审批
所有外发有去向和证据
```

## 数据分类

| 分类 | 示例 | 默认处理 |
|---|---|---|
| public | 已公开文档 | 可在允许 Workspace 内处理 |
| internal | 内部草稿、流程文档 | 仅 Workspace 内 Agent |
| confidential | 合同、客户数据、财务资料 | 受限 Agent + 目的绑定 |
| restricted | 身份信息、受监管数据、Secret | 默认拒绝；需明确合规策略 |

## 影响等级

| 等级 | 行为 | 默认策略 |
|---|---|---|
| L0 | 检索、总结、草拟 | 可自动执行 |
| L1 | 内部草稿、标签、临时任务 | 可预授权，完整审计 |
| L2 | 更新 CRM、提交代码、修改正式文档 | 显式授权或策略预授权 |
| L3 | 发邮件、公开发布、正式数据删除、签署、付款 | 当前版本始终拒绝（`NOT_AVAILABLE`）；没有可由确认解锁的公开执行器 |

## 委派约束

```text
child_permissions ⊆ parent_permissions ∩ task_policy_permissions
```

子 Agent 不得因为被委派而获得更高数据密级、更大工具权限或更宽外发范围。

## 默认拒绝项

```text
真实 Secret、Token、私钥
未授权外部网络传输
跨 Workspace 文件/资料读取
自动 Git push / 自动部署
自动邮件/社媒发布/付款/签署
删除正式数据、清空队列、删除集群资源
将外部文档指令当作系统策略
```

## 主要威胁与控制

| 威胁 | 控制 |
|---|---|
| 上下文污染 | FACT/DECISION/PROPOSAL/UNKNOWN 与显式 file artifact 绑定；fresh Agent/长期 Context 隔离由宿主负责，本项目不证明 |
| 路径越权 | Workspace allowlist、denylist、符号链接校验 |
| Secret 泄露 | 敏感文件名/追加路径拒绝；不是内容级 secret scanner，也不约束宿主绕过 |
| Prompt 注入 | 外部资料一律是不可信输入，不能改变 Policy 或 Capability |
| 权限膨胀 | TaskAuthority + 精确 Approval + persisted Lease，绑定 task hash/capability/scope/budget/session |
| 审查失独立 | Contract 创建时 `individual=SELF_REVIEW_AUDITED` 并标记 `sameSourceReview` / same-source review；`team`/`organization`/`regulated`/缺失配置=`INDEPENDENT_REQUIRED` 并拒绝同源审查。记录门禁不证明现实身份或宿主隔离 |
| 写入漂移/冲突 | 单目标 WriteIntent、expectedPreimageHash、apply 前重验、条件回滚；不保证多文件事务 |
| 建议幻觉传播 | 只有真实 `kind=file` bytes 可 VERIFIED；语义正确性仍需人工/宿主验证 |
| 外部误操作 | 当前 public executor 不提供网络/发布/部署能力；宿主其他工具不在门禁内 |
| 审计缺失 | 本地 Evidence/Receipt/ledger；不是签名、可信时间或外部见证 |

## 审批要求

| 动作 | 最低要求 |
|---|---|
| 创建草稿 | 策略允许时自动 |
| 修改内部正式产物 | 显式授权或预授权 |
| 提交代码/创建 PR | 明确用户/负责人批准 |
| 数据库迁移 | 明确批准 + 回滚方案 |
| 对外发送消息 | 当前版本不提供执行器，始终拒绝 |
| 公开发布 | 当前版本不提供执行器，始终拒绝 |
| 正式数据删除 | 当前版本不提供执行器，始终拒绝 |
| 支付、签署、医疗/法律最终结论 | 当前版本不提供执行器，始终拒绝 |
| 仓库普通文件 delete | 作为单目标 `repository-write`：精确 WriteIntent、当前 preimage、显式确认与条件回滚；不能推广为通用删除能力 |

## 证据最小化

Audit/Event Ledger 只保存：

```text
taskId、角色、策略版本、工具摘要、产物引用、审批引用、命令退出码、hash、脱敏短摘要
```

不保存：

```text
完整对话、原始推理、真实 Secret、完整敏感文件、完整客户资料、完整队列 payload
```
