# Stinky Cobbler 使用说明书

> 给 AI Agent 装上"受控治理"的本地控制面。本说明书覆盖：安装（在线 / 国内镜像 / 离线包）、接入 ZCode 与 Codex、日常使用、常见问题。

## 它是什么？

Stinky Cobbler 是一个**本地 AI 开发协作调度工具**：你提出需求，它自动生成多角色协作计划（planner 规划 → architect 架构 → builder 构建 → testwright 测试 → reviewer 评审 → verifier 验证 → scribe 记录），由宿主 AI（ZCode、Codex 等）按计划逐步执行，步骤间自动传递结果。同时它是**治理控制面**：每一步（读、写、删）都经过授权、留痕、可回滚。

它不是模型、不是聊天机器人，不依赖任何云服务，数据全部留在本地。

**30 秒理解**：让 AI 按多角色计划帮你干活，但每一步都在掌控之中——读要授权、写要留痕、删要备份、随时可回滚、全程可审计。

## 方式一：在线安装（有网络环境）

### 正常用户（终端操作）

```bash
npm install -g stinky-cobbler
stinky-cobbler --version      # 预期 2.0.0
stinky-cobbler doctor --json  # 预期 healthy: true
```

### 小白用户（把命令丢给 AI）

在 ZCode / Codex 对话里直接说：

```
帮我安装 stinky-cobbler，并接入当前工具
```

AI 会替你执行安装、配置、预览宿主接入，**在写入你的工具配置前会先给你预览并等你确认**。你全程只需要回复确认。

---

## 方式二：国内用户（镜像站）

### 正常用户（终端操作）

```bash
npm install -g stinky-cobbler --registry=https://registry.npmmirror.com
```

> npmmirror（淘宝镜像）会自动同步 npmjs 的包；新版本发布后可能有几分钟到几小时的同步延迟。镜像只支持安装，不支持发布/审计（属镜像基础设施限制）。

### 小白用户（把命令丢给 AI）

```
帮我安装 stinky-cobbler（用国内镜像），并接入当前工具
```

AI 会自动带上 `--registry=https://registry.npmmirror.com` 执行。

## 方式三：Releases 下载（离线 / GitHub 不便时）

在 GitHub Releases 页面（https://github.com/LJunP/StinkyCobbler/releases）下载附件。

### 附件说明

| 附件 | 用途 |
|---|---|
| `stinky-cobbler-2.0.0.tgz` | npm 标准包（有网时 `npm install -g ./stinky-cobbler-2.0.0.tgz`） |
| `stinky-cobbler-2.0.0-offline-full.zip` | **离线完整包（下载即用）**：含全部依赖，无需网络 |
| `stinky-cobbler-2.0.0.tgz.sha256` | 包完整性校验值（防下载被篡改） |
| `sbom.cyclonedx.json` | 依赖物料清单（供应链审计用） |
| `STINKY-COBBLER-MANUAL.md` | 本文档（使用说明书） |

### 正常用户（离线完整包，终端操作）

```bash
# 1. 下载 stinky-cobbler-2.0.0-offline-full.zip（需本机已装 Node ≥ 20）
# 2. 解压
unzip stinky-cobbler-2.0.0-offline-full.zip -d ~/apps

# 3. 让命令可用（macOS / Linux）
export PATH="$HOME/apps/stinky-cobbler-2.0.0-offline-full/bin:$PATH"

# 4. 验证
stinky-cobbler --version      # # 2.0.0
stinky-cobbler doctor --json
```

Windows（cmd）：

```cmd
set PATH=%USERPROFILE%\apps\stinky-cobbler-2.0.0-offline-full\bin;%PATH%
stinky-cobbler --version
```

> 国内访问 GitHub 不便时，可用加速代理下载（如 `https://ghproxy.com/https://github.com/...`），**下载后务必用 sha256 校验**：`shasum -a 256 stinky-cobbler-2.0.0-offline-full.zip`，与 Release 页面公布的哈希比对一致再使用。

### 小白用户（离线完整包，交给 AI）

把 zip 文件路径告诉 AI，说：

```
帮我安装这个 zip 里的 stinky-cobbler（这是离线完整包），解压并配置好，然后接入当前工具
```

AI 会完成解压、PATH 配置、宿主接入（写配置前仍会先预览等你确认）。

## 接入你的 AI 工具（一次性，三选一）

**ZCode**（获得 `/stinky-cobbler` 命令入口）：

```bash
stinky-cobbler entry install-host --dry-run    # 先预览
stinky-cobbler entry install-host --mcp        # 确认后安装（含本地 MCP）
```

**Codex**（无命令机制，走 skill 显式启用）：

```bash
stinky-cobbler entry install-host --host codex --mcp --dry-run
stinky-cobbler entry install-host --host codex --mcp
```

> `install-host` 是纯本地操作，离线环境同样可用；它会写入你的工具配置目录（`~/.zcode/` 或 `~/.codex/`），**写入前必须经过你的确认**——AI 代装时同样遵守。

## 日常使用

**ZCode 里**——输入命令激活（之后本会话免前缀）：

```
/stinky-cobbler 帮我检查当前项目的 README
```

**Codex 里**——显式启用 skill：

```
使用 stinky-cobbler 帮我检查当前项目的 README
```

工具统一按「结果 / 证据 / 边界 / 下一步」输出。关键决策（授权时长、删除确认、停止确认）由你点选/回复；常规文件写入自动放行（免确认 + 可回滚）。

**停止使用**：

```
停止使用该工具
```

工具先确认，确认后本会话完全退出（已签发的授权不自动撤销）。

## 常见问题

| 问题 | 解决 |
|---|---|
| `command not found` | PATH 未生效——重新 export 或新开终端 |
| `node: command not found` | 本机缺 Node——先装 Node ≥ 20 |
| EBADENGINE 警告 | 无害——工具在 Node 20 实测可用，可忽略 |
| 国内 npm 装不上 | 用方式二（npmmirror 镜像） |
| GitHub 下载慢/失败 | 加速代理 + sha256 校验，或等镜像同步后用方式二 |
| 想卸载 | 删解压目录（离线包）或 `npm uninstall -g stinky-cobbler`，再从 PATH 移除 |
